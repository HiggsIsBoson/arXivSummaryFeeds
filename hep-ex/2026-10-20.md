### [6] Neural Bayesian Online Calibration with Deficient Simulators for MADMAX Dark Matter Experiment
- **著者**: Nabil Salama
- **リンク**: https://arxiv.org/abs/2610.26343
- **要約**: dielectric haloscope である MADMAX には根本的な難しさがあります。axion 信号の増幅率である boost factor β²(ν) は直接測れません。しかもディスク配置を計算する disk-booster シミュレータは不完全で（ディスクの傾き、平面からのずれ、損失などをモデル化しきれていない）、ハードウェアに与えたピエゾの設定値と実際のディスク位置も一致しません。本論文はこれを「直接測れる出力（反射率）が少なくとも1つあり、知りたい量（β）は測れない」という一般的な較正問題として定式化しました。手順は次のとおりです。(1) 事前較正データから、状態に依存する「有効」シミュレータパラメータを学習し、シミュレータの不足分を吸収します。(2) normalizing flow で測定履歴から事後分布を amortized inference で即座に推定します。(3) 較正中は不確かさを伝播させつつ、次に与えるハードウェア指令を *expected improvement と information gain の兼ね合い* で最適化します。つまり Bayesian optimization と能動学習を組み合わせたオンライン調整ループです。反射率を使ってシミュレータを較正し、測れない boost factor を推定するのが狙いです。実機での検証は「進行中」で、現時点では手法の提案段階にとどまります。それでも、多数ディスクのブースターを決められた周波数に合わせ、β の系統誤差を見積もるという MADMAX 最大のボトルネックに正面から取り組んでいます。キャビティやブースター型 haloscope 全般の tuning と較正に応用できそうで、手法として注目です。
- **キーワード**: MADMAX, dielectric haloscope, axion, boost factor, normalizing flow, Bayesian calibration, simulation-based inference

### [2] ceci n'est pas un tagger, can an LLM flavour-tag a jet?
- **著者**: Andrea Coccaro, Andrea Milici, Lucio Derin
- **リンク**: https://arxiv.org/abs/2610.24954
- **要約**: タイトルはマグリットの「これはパイプではない」のもじりです。ATLAS のジェットの再構成済み構成粒子情報だけを LLM に渡し、b / c / light / τ のフレーバー確率を出力させました。条件は「コード生成禁止」で、事前学習で得た物理知識だけに頼って推論させています。結果として、ATLAS の既存アルゴリズムと比較できる程度の「非自明な」識別性能が得られました。さらに各判定に自然言語で理由を付け、その内容が displaced track、二次崩壊点、soft lepton、多重度や collimation といった既知の物理的特徴と合っていたと報告しています。もちろん GN2 系の専用 tagger に勝つ話ではありません。論点は「LLM を物理知識の貯蔵庫として解析に使えるか」と、解釈可能性です。ATLAS の b-tagging をよくご存知の立場からは、ベースラインの選び方や入力のトークン化、LLM の訓練データに文献由来の情報が混入している可能性といった点を批判的に読むと面白いと思います。11ページ、11図。
- **キーワード**: LLM, flavour tagging, b-tagging, ATLAS, interpretability, ML

### [4] Low-Latency Beam-Background Suppression for the BESIII Trigger System Using Machine Learning Trained on Experimental Data
- **著者**: Hanlin Zhang, Minggang Zhao, Junhao Yin, Boping Chen, Jingzhou Zhao, Wenxuan Gong, Ke Li
- **リンク**: https://arxiv.org/abs/2610.26148
- **要約**: BESIII の L1 トリガーで、ビーム起源背景を ML で落とす研究です。学習はシミュレーションではなく *実データ* で行っています。入力は L1 の 48 個の binary トリガー条件だけで、「トラッキング + TOF」と「EMC」の2つの構成それぞれに小さな NN 分類器を用意しました。hadron 事象の効率をそろえて比べると、既存のトリガー選択より beam-background の false positive が 20–60% 減ります（構成と重心エネルギーによる）。random trigger データでも同じ傾向を確認しています。FPGA 合成解析で低レイテンシ実装が可能なことも示しており、hls4ml 系の流れに属する実用的な成果です。入力が 48 bit と小さいので、「すでにある L1 プリミティブの論理結合を ML で最適化し直す」と言い換えられる、地味ですが堅実な仕事です。将来の STCF/Super Tau-Charm や高ルミノシティ e⁺e⁻ のトリガー設計への指針になります。
- **キーワード**: BESIII, L1 trigger, beam background, FPGA, data-driven ML

### [9] Development of microwave multiplexed readout for athermal phonon TES-based detectors (from physics.ins-det)
- **著者**: Tran Tsan, D. A. Bennett, D. T. Becker, J. A. B. Mates, J. N. Ullom, et al.（LBNL / NIST / CU Boulder）
- **リンク**: https://arxiv.org/abs/2610.24300
- **要約**: TESpA / SPICE / HeRALD 系統の、sub-eV 閾値の athermal phonon TES 検出器を大規模化するため、mm 波や X 線 TES で実績のあるマイクロ波 SQUID 多重化読み出し（μmux）を移植しました。希釈冷凍機のテストベッドで多重読み出しの動作とノイズ特性を実証しています。寄生的な背景負荷を 1 fW 未満に抑え、極低温でのインライン RF フィルタの実用的な解決策も示しました。低エネルギー過剰事象（LEE）の理解や、sub-GeV DM、CEvNS、QIS 応用でターゲット質量とセンサー数を増やすためのハードウェア基盤です。量子センサーによる DM 探索のハードウェア面としてご興味に近いと思います。5ページ、IEEE TAS（ASC 2026）投稿。
- **キーワード**: TES, microwave SQUID multiplexing, athermal phonon, sub-GeV DM, CEvNS, cryogenic RF

- **キーワード**: dual-phase LXe TPC, 0νββ, electroluminescence imaging, XLZD
