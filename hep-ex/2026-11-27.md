## ピックアップ 3本

### [3] Letter of Intent: AN Underground Belayed In-Shaft (ANUBIS) detector
- **著者**: ANUBIS Collaboration
- **リンク**: https://arxiv.org/abs/2611.34882
- **要約**: ATLAS 実験ホールの天井とアクセスシャフトに、合計約 1600 m² の RPC トラッキング層を置く計画の LoI です。ATLAS とホールの間の空気を崩壊体積として使い、long-lived particle (LLP) の displaced decay を捉えます。HL-LHC の 3 ab⁻¹ で、エキゾチックな Higgs 崩壊（h→ss、s は長寿命スカラー）への感度が 2〜3 桁上がる見込みです。heavy neutral lepton は混合 |U|² ~ 2×10⁻⁸ まで探れるとしています。2024–2025 年には小型の実証機 pro-ANUBIS を運転済みです。MATHUSLA や CODEX-b と同じく「横に置く LLP 検出器」の流れに入りますが、遮蔽を足さずに ATLAS 本体を active veto として使える点と、IP からの距離が近く比較的短い cτ もカバーできる点がこの案の売りです。SUSY の RPV や long-lived neutralino、hidden valley などの LLP シナリオに関心があるなら、感度曲線の比較は読む価値があります。
- **キーワード**: ANUBIS, LLP, HL-LHC, ATLAS cavern, HNL, exotic Higgs decay, RPC

### [12] The Look-Elsewhere Effect in Searches for New Physics: from Classical Methods to Machine Learning（hep-ph からの cross-list）
- **著者**: Gaia Grosso, Sergio Rodriguez-Benitez, Louis Lyons
- **リンク**: https://arxiv.org/abs/2611.34888
- **要約**: Look-Elsewhere Effect (LEE) のレビューです。連続的なスキャン（Gross–Vitells の上方交差法など）と離散的なスキャンでの補正の仕方を整理し、ML を使った探索にも話を広げています。ML 探索では、学習やモデル選択の段階で入る暗黙の post-selection bias が問題になります。anomaly detection や NPLM 型の model-independent search のように、何をスキャンしたかがはっきりしない場合に global significance をどう出すかが要点です。最後に未解決の問題と、発見の有意度を報告する時の推奨をまとめています。数値の新しい結果はありませんが、ML ベースの BSM 探索で有意度を主張する前の手引きとして手元に置いておける内容です。
- **キーワード**: look-elsewhere effect, global significance, anomaly detection, ML, statistics

### [9] First Order Real Resonant Digital Filters and A Novel Orthogonal State Generator（eess.SP からの cross-list）
- **著者**: Edward J. Daw
- **リンク**: https://arxiv.org/abs/2611.34677
- **要約**: 実数演算だけで組んだ1次の共振デジタルフィルタと、直交状態生成器 FOREST を提案し、DSP ハードウェアに実装しています。想定する用途は、リアルタイム信号処理、phase-locked loop、高 Q 共振器の読み出しです。abstract に物理の数値はありません。とはいえ、高 Q キャビティを使う axion haloscope や高周波重力波探索では、共振器の追従（PLL）や狭帯域の I/Q 復調を FPGA や DSP 上で軽く回す必要があります。そうした読み出し系の要素技術として使える可能性があります。
- **キーワード**: digital resonator, orthogonal state generator, PLL, DSP, high-Q resonator readout
